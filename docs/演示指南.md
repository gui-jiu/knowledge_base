# 掌柜智库 · 项目演示指南

> 本指南介绍如何启动并演示本 RAG 系统。

---

## 一、演示前准备

### 1. 确保中间件运行（阿里云服务器）

Milvus(19530) / MongoDB(27017) / MinIO(9000) 需在服务器上运行：

```bash
# 在服务器上检查
docker ps | grep -E "milvus|mongo|minio"
```

### 2. 准备演示文档

**建议使用图片较少的 PDF**（图片处理会调用 VL 模型，有限流）。

| 文档 | 图片数 | 预计耗时 | 推荐 |
|------|--------|----------|------|
| `hak180产品安全手册.pdf` | 7 张 | 约 40 秒 | ✅ 推荐 |
| `hak180使用说明书.pdf` | 208 张 | 10+ 分钟 | ❌ 不推荐 |

> 图片处理节点对每张图调用一次 VL 模型，且限流为每 30 秒 10 次，图片过多时耗时较长。

### 3. 启动服务

```powershell
# 在项目根目录执行
powershell -ExecutionPolicy Bypass -File scripts\start_demo.ps1
```

或手动分别启动：

```powershell
$env:PYTHONPATH = "D:\opencode\knowledge_base"
uv run python -m uvicorn app.import_process.api.import_service:app --host 0.0.0.0 --port 8000
uv run python -m uvicorn app.query_process.api.query_service:app --host 0.0.0.0 --port 8001
```

## 二、演示流程

### 第 1 步：文档导入（约 1 分钟）

1. 浏览器打开 **http://localhost:8000/import.html**
2. 选择 `hak180产品安全手册.pdf`，点击「开始导入」
3. 观察 7 个节点的进度依次点亮：
   入口判断 → PDF转Markdown → 图片处理 → 文档切分 → 主体识别 → 向量化 → 存入向量库

### 第 2 步：智能问答（约 2 分钟）

1. 打开 **http://localhost:8001/chat.html**
2. 提问：**"HAK180烫金机的安全注意事项有哪些？"**
3. 观察 SSE 流式输出的打字机效果
4. 继续追问：**"那它的使用环境有什么要求？"**（展示多轮对话）

### 第 3 步：查看数据与接口

- **接口文档**：http://localhost:8001/docs（Swagger UI）
- **Milvus 数据**：http://120.26.163.3:7000（Attu 可视化，查看 `kb_chunks` / `kb_item_names` 集合）

## 三、常见问题

**Q: 导入很慢/卡住？**
A: 图片处理节点调用 VL 模型有限流（每 30 秒 10 次）。建议使用图片较少的 PDF。

**Q: 联网搜索没有结果？**
A: 检查 `.env` 的 `MCP_DASHSCOPE_BASE_URL` 是否配置。

**Q: 端口被占用？**
A: `Get-NetTCPConnection -LocalPort 8000,8001` 找到进程后 `Stop-Process`。

**Q: 如何停止服务？**
A: 关闭弹出的两个命令行窗口，或：
```powershell
Get-NetTCPConnection -LocalPort 8000,8001 -State Listen | ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }
```
